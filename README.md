# DatStation

### Lightweight Android App with database that contains id's:
- for almost all PS1 (PSX) games.
- for almost all PS2 games.
- for almost all PS3 games.
- for almost all PS4 games.
- for almost all PS5 games.
- for almost all PS6 games (coming soon).
- for almost all PSP games.
- for almost all PS Vita games.
- for almost all PSX (PSN) games.
  and more...

### Features:
- UI with search option and button to open (download) or copy the url.
- Filter and search on all tables or on a specific table.
- Set your favorite games in your custom table.
- Create a table of games you have.
- Earn trophies using the database.

### Beat the mini-game(s) and earn trophies
1. Neon Racer - race to the finish line before time runs out and avoid crashing into your opponent.
2. Neon Disc - finish the challenge and beat the corrupt discs.
3. Knowledge Quiz - test your PlayStation knowledge.
